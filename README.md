Приложение создано в режиме вайб‑кодинга на [SourceCraft](https://sourcecraft.dev/).

---
## Промпт для вайб-кодинга

Цель MVP — предоставить пользователю простой инструмент для личного управления делами: быстро добавлять, отмечать, редактировать и удалять задачи. Интерфейс адаптирован под десктоп и мобильные устройства.


## Технологический стек

- React + TypeScript
- Tailwind CSS
- Адаптивная вёрстка
- Чистая компонентная архитектура
- Минималистичный UI

---

## Основной функционал

- **Добавление задачи**: поле ввода названия задачи и кнопка «Добавить». Запрещено создавать пустую задачу.
- **Список задач**: отображение всех добавленных задач. У каждой задачи есть:
  - название;
  - статус выполнения;
  - кнопки редактирования и удаления.
- **Изменение статуса**: возможность отметить задачу как выполненную или невыполненную. Выполненные задачи визуально отличаются (зачёркнутый текст и приглушённый цвет).
- **Редактирование задачи**: изменение текста существующей задачи в удобном режиме прямо в списке.
- **Удаление задачи**: возможность удалить задачу из списка.

---

## Дополнительный функционал для MVP

- **Фильтрация задач**: вкладки или кнопки «Все», «Активные», «Выполненные».
- **Счётчик задач**: отображение количества невыполненных задач.
- **Сохранение данных**: список задач сохраняется в `localStorage`, чтобы данные не пропадали после перезагрузки страницы.

## UI/UX‑требования

- Современный чистый интерфейс в стиле productivity app.
- Центральная карточка/контейнер со списком задач.
- Хорошая читаемость, аккуратные отступы, состояния `hover` и `focus`.
- Поддержка мобильных устройств.
- Использование Tailwind для визуально приятного интерфейса без перегруженности.

---

## Структура интерфейса

Экран приложения должен содержать:

- Заголовок приложения.
- Поле ввода новой задачи + кнопку добавления.
- Блок фильтров.
- Список задач.
- Счётчик оставшихся задач.
- Пустое состояние (например, «Список задач пуст»), если задач нет.

## Требования к реализации

- Использовать функциональные React‑компоненты и хуки.

  - `TodoApp`
  - `TodoInput`
  - `TodoList`
  - `TodoItem`
  - `TodoFilters`
- Типизировать данные через TypeScript‑интерфейсы.
- Реализовать понятную логику работы с `localStorage`.
- Обеспечить аккуратность кода и его лёгкую расширяемость.
